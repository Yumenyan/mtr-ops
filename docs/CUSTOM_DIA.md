# ダイヤ編成ツール(発車時刻の定義)

「各路線のホームを発車する時刻」をゲーム内で決めるツールです。MTR の停車時間とは無関係に、種別ごとに違う発車時刻や、発車時刻単位の正確な待避を実現します。
MTR の jar も、MTR に保存されているデータ(路線・車庫・ホーム・レール・出庫設定)も一切書き換えません。通常の鉄道ダッシュボードの動作も変わりません。
車庫の設定・出庫の自動調整はありません(列車は MTR の出庫設定のまま出庫します)。

## 使い方(すべてゲーム内)

1. **ダイヤ編成ツール**を手に持って使う(右クリック)。入手はクラフト(MTRの鉄道ダッシュボード + 時計)かクリエイティブの「移動手段」タブ。`/mtrops dia` でも開けます。
2. 路線の一覧から路線を選ぶ → 「ダイヤ運転 ON」。
3. **発車**: 路線のホームの並びに、**初便が各ホームを発車する時刻**を入力します。
   - 続行便は「初便 + 運転間隔」で、各ホームを同じ差で発車します。先頭の行(始発ホーム)を変えると全ホームが一緒にずれます。
   - 駅間の時間(緑 = 足りる / 赤 = MTRの走行時間の目安より短い)を見ながら決めます。目安は MTR の理想走行に、実績の比率を掛けたものです。
   - 入力しなかったホームは、目安(走行時間 + MTRの停車時間)で埋めます。「目安に戻す」で全ホームを作り直します。
4. **間隔**: 初発・終発と、時間帯ごとの運転間隔(分:秒)。
5. 右側の**診断**が入力に合わせてリアルタイムに変わります。
   - 詰まる: 同じホームで列車が重なる / 駅間で後ろの列車が追い付く(追い越せない) / 運転間隔が近すぎる
   - 待避OK: 駅で着く順と出る順が入れ替わり、ホームが別 = 待避できる(通過待ち・先行待ちとして表示)
   - 時間不足: 駅間の時間が MTR の走行時間の目安より短い
6. 左下の「保存」でサーバーへ送られます(権限: MTRと同じ。`requireOpToEdit` でOPのみにできます)。

最初のダイヤ編成ツールの画面(路線の一覧)の右側には、ダイヤ運転にしたすべての路線の診断が出ます。「最小間隔」は同じホームを使う列車の最小の間隔(診断の基準)です。

## 待避のしかた

快速が通過するホーム(MTR で停車時間 0 のホーム)と、普通が停車するホームを別にした路線(待避線のある駅)を作り、
普通の発車時刻を快速の通過より後ろに置きます。診断が「待避OK」を出せば、その発車時刻で正確に待避します。
列車は早く着いたらドアを開けたまま発車時刻まで待ち、遅れているときはドアが一定時間(既定3秒)開いたらすぐ閉めて発車します。

## 列車の動き(ダイヤ運転の路線の列車だけ)

| 機能 | 内容 |
|---|---|
| 発車時刻 | 表の時刻ちょうどに発車します。始発ホームに着いた列車には、次に発車する便が割り当てられます。 |
| ATC | 前方の閉塞に先行列車がいると、その手前で止まれる速度に連続で制限します。 |
| ATS | ATC と同じ判定で、速度を段階に丸めます。 |
| 回復運転 | 遅れが設定秒数以上のとき、レールの最高速度 + 指定 km/h(上限まで)で走れます。 |

速度や停車を変えた列車は、巻き戻って見えないよう 4tick ごとにクライアントへ同期します。
時刻はサーバーの時計(既定はサーバーのタイムゾーン。`config/mtrops.json` の `timeZone` で変更可。例 `"Asia/Tokyo"`)です。

## Web・APIでの扱い
- `/api/dia` で設定・路線ごとの時刻表(`?route=ID` で便を含める)・診断(`issues`)・運行中の列車の便と遅れを読めます(読み取りのみ)。
- 到着予想(`etas`)は時刻表の到着(`scheduled`)と、早着時の待ち合わせを反映した見込み(`time`)を出します。
- 駅の時刻表(`/api/schedule/駅`)は、ダイヤ運転の路線を時刻表どおり(通過を含む)に出します。
- Webアプリでは路線に「ダイヤ」の印が付き、列車詳細で「定刻 ▶ 見込」を表示します。

## できないこと(MTR の仕様)
- 列車ごとに入るホームを変えることはできません(ホームの並びは「路線+車庫」で経路生成時に決まります)。
- 初便の時刻に対する各ホームの差は全便共通です(時間帯ごとに駅間の時間を変えることはできません)。

## 技術メモ
- 差し込み先: `Train.simulateTrain`(速度・停車時間)、`TrainServer.simulateTrain`(同期)。
- 差し込みが効かない場合はゲームを止めず、ログにエラーを出してダイヤ運転の列車制御だけ無効になります。
